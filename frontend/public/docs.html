Backend API

Interactive API docs (Swagger UI) and OpenAPI spec are served by the backend.

  • API Docs (Swagger) — try endpoints interactively
  • OpenAPI JSON — curated 29-path canonical contract
  • OpenAPI V2 Public — promoted public contract split from runtime
  • OpenAPI Internal — internal and operational endpoints
  • Contract Split V2 Report — promoted vs internal endpoint decision log
  • Contract Split V2 JSON — machine-readable public/internal split
  • Runtime Expanded OpenAPI — full runtime-derived contract
  • Runtime Supplement — runtime-only endpoints outside the original canonical contract
  • API Drift Report — markdown summary of canonical vs runtime drift
  • API Drift JSON — machine-readable drift summary
